# Dashboard_Test
สร้างเว็บไซต์ Dashboard สำหรับวิเคราะห์และแสดงผลข้อมูลด้วย D3.js
Line Chart และ Scatter Plot สำหรับรายได้, Bar Chart สำหรับอุณหภูมิ และ Scatter Plot สำหรับประสิทธิภาพการใช้เชื้อเพลิง
ออกแบบ UI ให้มีความ Modern, Clean และ Professional ใช้โทนสี Soft/Pastel ที่ดูน่าสนใจแต่ไม่ฉูดฉาด พร้อมส่วน Key Findings สำหรับสรุปข้อมูลสำคัญของ Data Visualization ในการวิเคราะห์ข้อมูล
