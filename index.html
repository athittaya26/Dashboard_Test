DATA VISUALIZATION

ประโยชน์ของการใช้เทคโนโลยี การแสดงผลข้อมูล

การแสดงผลข้อมูลช่วยให้ผู้วิเคราะห์ เข้าใจข้อมูลและค้นพบประเด็นสำคัญได้ง่ายขึ้น

01

ช่วยให้เข้าใจข้อมูลได้ง่าย

การนำข้อมูลที่อยู่ในรูปแบบตาราง มาแสดงเป็นกราฟช่วยลดความซับซ้อน และทำให้ผู้ใช้สามารถเข้าใจข้อมูล ได้อย่างรวดเร็ว

ตัวอย่าง

Bar Chart ทำให้สามารถเห็นความแตกต่าง ของอุณหภูมิในแต่ละเมืองได้ทันที

02

ช่วยมองเห็นแนวโน้ม

กราฟช่วยให้สามารถสังเกตการเปลี่ยนแปลง และแนวโน้มของข้อมูลได้ง่าย โดยเฉพาะข้อมูลที่มีลำดับตามเวลา

ตัวอย่าง

Line Chart ช่วยให้เห็นแนวโน้ม รายได้ของแต่ละ Branch ตั้งแต่ January ถึง April

03

สนับสนุนการตัดสินใจ

การแสดงผลข้อมูลทำให้สามารถ เปรียบเทียบข้อมูลและใช้ข้อมูล ประกอบการตัดสินใจได้อย่างมีประสิทธิภาพ

ตัวอย่าง

Scatter Plot สามารถช่วยวิเคราะห์ ความสัมพันธ์ระหว่างขนาดเครื่องยนต์ และค่า MPG

ANALYSIS

ข้อดีและข้อเสียของ Data Visualization

การวิเคราะห์ข้อดีและข้อจำกัด ของเทคโนโลยีการแสดงผลข้อมูล

+
ADVANTAGES

ข้อดี

01 — วิเคราะห์ข้อมูลได้รวดเร็ว

กราฟช่วยให้ผู้วิเคราะห์สามารถมองเห็น แนวโน้มและความแตกต่างของข้อมูล ได้เร็วกว่าการอ่านข้อมูลจากตาราง

02 — เปรียบเทียบข้อมูลได้ง่าย

สามารถนำข้อมูลหลายกลุ่มมาแสดง ในรูปแบบเดียวกัน ทำให้เปรียบเทียบ ข้อมูลได้สะดวก

03 — ช่วยค้นพบความสัมพันธ์

การใช้ Scatter Plot สามารถช่วยให้ เห็นรูปแบบหรือความสัมพันธ์ระหว่าง ตัวแปรที่อาจมองไม่เห็นจากตาราง

−
LIMITATIONS

ข้อเสีย

01 — อาจทำให้ตีความผิด

หากเลือกชนิดกราฟหรือกำหนดแกน ไม่เหมาะสม อาจทำให้ผู้ใช้เข้าใจ ข้อมูลหรือแนวโน้มคลาดเคลื่อน

02 — ใช้เวลาในการออกแบบ

การสร้าง Dashboard ที่มีคุณภาพ ต้องใช้เวลาในการออกแบบกราฟ สี การจัดวาง และ Interaction

03 — อาจไม่แสดงรายละเอียดทั้งหมด

การสรุปข้อมูลเป็นกราฟอาจทำให้ รายละเอียดบางส่วนของข้อมูลต้นฉบับ ไม่ได้ถูกแสดงทั้งหมด
